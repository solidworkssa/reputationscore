# ReputationScore

On-chain reputation tracking system.

## Features
- Multi-chain support (Base & Stacks)
- Secure Contract Logic
- React/Next.js Frontend

## Contracts
- Base: `contracts/base/src/ReputationScore.sol`
- Stacks: `contracts/stacks/contracts/reputationscore.clar`

## Setup
```bash
pnpm install
pnpm dev
```
